# KompasLink

Диагностический прототип Windows-утилиты для работы с внешними файловыми ссылками КОМПАС-3D. Целевая версия — v18; совместимость с её SDK и установленной системой пока не подтверждена.

Русскоязычное окно показывает подключение, версию КОМПАС, путь активного документа, признаки изменения и режима только для чтения. Кнопка «Обновить ссылки» запускает чтение. Таблица показывает исходные адреса, состояния файлов и пояснения; выбор строки показывает полный адрес. Область результатов содержит сообщения и ошибки текущего запуска.

Адаптер подключается к уже запущенному КОМПАС через `KOMPAS.Application.5`, запрашивает версию через `ksGetSystemVersion`, получает API 7 методом `ksGetApplication7` и читает активный документ. Названия методов проверены по официальной онлайн-справке более новых SDK; это не является подтверждением наличия и сигнатур в v18.

## Требования

- Windows и установленный КОМПАС-3D с зарегистрированным COM API.
- Один запущенный экземпляр КОМПАС, одинаковый пользователь и уровень прав с утилитой.
- Для первого испытания — локальная тестовая копия `.a3d` или `.m3d`.
- Для воспроизводимой сборки — Go 1.27.3 (версия закреплена в `.go-version`), доступ к зависимостям из `go.mod`, включая Walk и go-ole. CGo и C-компилятор не требуются.
- Для запуска собранного EXE Go, .NET и браузерный движок не требуются. Manifest Common Controls 6 встроен в EXE.

## Сборка

PowerShell, из каталога проекта, для первоначального испытания на Windows x64 и КОМПАС x64:

```powershell
.\build.ps1
```

Для испытания с 32-разрядной установкой: `.\build.ps1 -Architecture 386`. Межразрядное подключение здесь не проверено. Скрипт создаёт ресурс manifest инструментом `github.com/akavel/rsrc` v0.10.2 и собирает окно и консольную диагностику. Запускать окно следует только после успешного завершения скрипта. Политика выполнения PowerShell должна разрешать запуск локального скрипта.

Скрипт проверяет точную версию компилятора и целостность скачанных модулей, отключает CGo и записывает `bin/SHA256SUMS.txt` и `bin/build-info.txt`. Флаги сборки убирают зависимость результата от расположения исходников и состояния Git. Упаковка, обфускация и обход антивируса не применяются. Старый EXE и новая сборка могут иметь разные контрольные суммы.

Если корпоративная политика запрещает PowerShell-скрипты, не меняйте её самостоятельно. Согласуйте сборку с администратором. Ограниченная проверка исходников и процедура разбора антивирусного срабатывания описаны в [docs/BUILD-REVIEW.md](docs/BUILD-REVIEW.md).

## Запуск

Откройте сохранённую локальную тестовую копию `.a3d` или `.m3d` в КОМПАС, запустите `bin/kompaslink.exe` двойным щелчком и нажмите «Обновить ссылки». В готовом архиве Windows достаточно распаковать файлы и открыть `kompaslink.exe`; PowerShell и компилятор для этого не нужны. Окно также можно открыть из PowerShell:

```powershell
.\bin\kompaslink.exe
```

Окно не запускает КОМПАС автоматически. При отсутствии приложения или документа объяснение появится в результатах. Поля очищаются перед каждым чтением, чтобы старые сведения не выглядели актуальными после ошибки. После переключения документа в КОМПАС нажмите обновление снова. Сообщения хранятся только в памяти текущего запуска.

Консольная диагностика сохранена отдельно. Для получения JSON-отчёта:

```powershell
.\bin\kompaslink-diag.exe | Out-File -Encoding utf8 diagnostic.json
$LASTEXITCODE
```

Результат — JSON с полями `report` и, при ошибке, `error`. Код завершения 1 означает ошибку подключения или чтения; 0 — завершённое чтение, в том числе при отсутствии активного документа. Состояние `document_observed` означает только получение сведений и не разрешает редактирование.

`no_active_document` — документа нет; `document_without_saved_path` — API не сообщил абсолютный путь и каталог; `document_has_unsaved_changes` — КОМПАС сообщил несохранённые изменения. `has_saved_path` не доказывает наличие файла на диске. `type_id` оставлен числом до проверки перечислений SDK v18.

Ошибка получения версии не останавливает чтение активного документа и ссылок. В окне она отображается как предупреждение, в JSON — в `version_error`; неизвестная версия не подменяется предполагаемой. Если COM-вызов завершился без исключения, предупреждение содержит тип VARIANT, значение результата и выходные компоненты версии.

В JSON поле `references_read` отличает прочитанный пустой список от неудавшегося чтения. `references_error` содержит причину отказа. Ошибка чтения ссылок сохраняет уже полученные сведения о документе; CLI возвращает код 1 и при этой ошибке.

Чтение использует `IKompasDocument1.ExternalFilesNames(true)`. GUID интерфейса и сигнатура свойства подтверждены разбором предоставленной утилиты ChangeExternalLink; это не проверка SDK v18. При ошибке числа аргументов выполняется документированный вызов без аргумента. При отсутствии интерфейса или другой ошибке API программа показывает причину. Возвращаемый SAFEARRAY проверяется на тип и размерность; учитывается его нижняя граница, ошибки чтения элементов не игнорируются. Этот список не сообщает тип связи и не гарантирует полноту зависимостей.

Для абсолютных путей с буквой диска различаются «Найден», «Отсутствует», «Нет доступа», «Проверить не удалось». URI, относительные, сетевые и специальные пути не проверяются как обычные локальные файлы. Относительные пути остаются неразрешёнными, пока не подтверждены правила КОМПАС-18. Наличие файла не доказывает его соответствие исходной детали.

## Ограничения

Замена ссылок отключена: для v18 не подтверждены доступность метода и набор затрагиваемых документов. Резервное копирование и сохранение CAD-документов отсутствуют. Не вызываются создание экземпляра КОМПАС, открытие или закрытие документов, сохранение и `Quit`. SQL-база ЛОЦМАН не используется.

Все COM-операции одного запроса, включая освобождение объектов, выполняются синхронно в STA на закреплённом потоке ОС. В окне запрос выполняется в отдельной goroutine; интерфейс получает через очередь Walk только обычные Go-значения, после освобождения COM-объектов. Элементы окна обновляются только его потоком. При ошибке обязательного свойства диагностика прекращается, неизвестные значения не принимаются за `false`.

Подключение через ROT не выбирает экземпляр по PID. При нескольких установках или процессах выбранный COM-сервер может отличаться от ожидаемого; проверяйте полученную версию. Прототип не содержит подписок на события, фонового COM-цикла, автоматических повторов и гарантированного тайм-аута зависшего COM-вызова.

Во время чтения повторный запуск и обычное закрытие окна заблокированы до освобождения COM-объектов. При зависшем вызове окно продолжит обрабатывать сообщения, но закончить чтение или безопасно отменить его по тайм-ауту прототип не умеет.

Запуск и визуальная проверка окна на Windows, а также интеграция с реальным КОМПАС-18 пока не проведены. Сведения об исследовании и ручной проверке — в [docs/API-EVIDENCE.md](docs/API-EVIDENCE.md).
