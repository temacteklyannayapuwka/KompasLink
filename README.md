# KompasLink

Диагностический прототип Windows-утилиты для работы с внешними файловыми ссылками КОМПАС-3D. Целевая версия — v18; совместимость с её SDK и установленной системой пока не подтверждена.

Текущая реализация подключается к уже запущенному КОМПАС через `KOMPAS.Application.5`, запрашивает версию через `ksGetSystemVersion`, получает API 7 методом `ksGetApplication7` и читает активный документ: имя, каталог, полное имя, числовой тип, признаки изменения и режима только для чтения. Названия методов проверены по официальной онлайн-справке более новых SDK; это не является подтверждением наличия и сигнатур в v18.

## Требования

- Windows и установленный КОМПАС-3D с зарегистрированным COM API.
- Один запущенный экземпляр КОМПАС, одинаковый пользователь и уровень прав с утилитой.
- Для первого испытания — локальная тестовая копия `.a3d` или `.m3d`.
- Для сборки — Go 1.23 или новее, доступ к зависимостям `go-ole` и `x/sys`. CGo и C-компилятор не требуются.
- Для запуска собранного EXE Go не требуется.

## Сборка

PowerShell, из каталога проекта, для первоначального испытания на Windows x64 и КОМПАС x64:

```powershell
$env:GOOS = "windows"
$env:GOARCH = "amd64"
$env:CGO_ENABLED = "0"
go mod download
go vet ./...
New-Item -ItemType Directory -Force bin | Out-Null
go build -o bin/kompaslink.exe ./cmd/kompaslink
```

Для испытания с 32-разрядной установкой замените `amd64` на `386` и пересоберите. Межразрядное подключение здесь не проверено.

## Запуск

Откройте тестовый документ в КОМПАС и выполните из PowerShell:

```powershell
.\bin\kompaslink.exe
```

Для сохранения диагностического отчёта:

```powershell
.\bin\kompaslink.exe | Out-File -Encoding utf8 diagnostic.json
$LASTEXITCODE
```

Результат — JSON с полями `report` и, при ошибке, `error`. Код завершения 1 означает ошибку подключения или чтения; 0 — завершённое чтение, в том числе при отсутствии активного документа. Состояние `document_observed` означает только получение сведений и не разрешает редактирование.

`no_active_document` — документа нет; `document_without_saved_path` — API не сообщил абсолютный путь и каталог; `document_has_unsaved_changes` — КОМПАС сообщил несохранённые изменения. `has_saved_path` не доказывает наличие файла на диске. `type_id` оставлен числом до проверки перечислений SDK v18.

## Ограничения

Внешние ссылки не читаются и не заменяются. GUI, резервное копирование и сохранение CAD-документов отсутствуют. Не вызываются создание экземпляра КОМПАС, открытие или закрытие документов, сохранение и `Quit`. SQL-база ЛОЦМАН не используется.

Все COM-операции, включая освобождение объектов, выполняются синхронно в STA на закреплённом потоке ОС. Наружу адаптер возвращает только обычные Go-значения. При ошибке обязательного свойства диагностика прекращается, неизвестные значения не принимаются за `false`.

Подключение через ROT не выбирает экземпляр по PID. При нескольких установках или процессах выбранный COM-сервер может отличаться от ожидаемого; проверяйте полученную версию. Прототип не содержит подписок на события, фонового COM-цикла, автоматических повторов и гарантированного тайм-аута зависшего COM-вызова.

Проверка на реальном КОМПАС-18 не проведена. Сведения об исследовании и ручной проверке — в [docs/API-EVIDENCE.md](docs/API-EVIDENCE.md).
